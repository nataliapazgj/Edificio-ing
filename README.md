# Edificio Ingeniería — MCOC

Modelo estructural 3D completo del Edificio de Ingeniería.

## Objetivo Semana 2

- construir la geometría estructural completa;
- identificar nodos, vigas, columnas y muros;
- realizar chequeos iniciales de conectividad;
- generar un viewer 3D;
- preparar la geometría para OpenSeesPy y Unity.

## Estructura del proyecto

- `data/`: información estructural y geométrica;
- `src/`: código Python;
- `tests/`: pruebas y verificaciones;
- `results/`: resultados del análisis;
- `figures/`: visualizaciones;
- `unity/`: proyecto/viewer Unity;
- `reports/`: documentación semanal.
