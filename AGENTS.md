# AGENTS.md

## Proyecto

Modelo estructural 3D completo del Edificio de Ingeniería.

## Reglas generales

- No inventar dimensiones estructurales.
- Toda geometría debe provenir de los planos o de supuestos explícitamente documentados.
- La geometría debe almacenarse fuera de Unity.
- Los IDs de nodos y elementos deben ser reproducibles.
- Antes de modificar el modelo, revisar conectividad y unidades.
- Todo cambio importante debe acompañarse de una verificación.

## Flujo de trabajo

Issue → Plan → Build → Test → Review → Commit
